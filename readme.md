# SI Les Mandarin

Aplikasi satu file (`index.html`), tanpa instalasi.

## Online lewat GitHub Pages
1. Buat repository baru di GitHub, upload `index.html` dan `README.md`.
2. Buka **Settings → Pages**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
3. Tunggu 1–2 menit. Alamatnya: `https://USERNAME.github.io/NAMA-REPO/`.

## Login awal
Username `admin`, password `admin123`. Segera ganti di menu **Akun**.

## Catatan penting
- Data tersimpan di browser (localStorage) pada perangkat yang dipakai, tidak dibagi antar perangkat. Gunakan **Akun → Unduh backup** secara rutin.
- Login dicek di sisi browser, cukup untuk membatasi akses sehari-hari tetapi bukan keamanan setingkat server. Untuk data bersama antar perangkat dan login server, aplikasi perlu dihubungkan ke database online (misalnya Supabase atau Firebase).
